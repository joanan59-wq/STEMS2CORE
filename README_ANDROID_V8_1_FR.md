# STEM2CORE V8.1 — Android

Cette version prépare le paquet de publication Android : PWA installable (HTTPS requis), icônes 192/512, manifeste et service worker. Elle conserve le backend de la V8 avec les fichiers Docker manquants déjà ajoutés.

**Ce n'est pas encore une application Android publiée ni un moteur IA cloud actif.** Le déploiement doit être effectué dans un compte d'hébergement appartenant à l'utilisateur. Consultez `DEPLOIEMENT_ANDROID_V8_1_FR.md`.
